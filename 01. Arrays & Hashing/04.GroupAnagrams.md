# 49. Group Anagrams
Medium

Example 1:
```
Input: strs = ["act","pots","tops","cat","stop","hat"]

Output: [["hat"],["act", "cat"],["stop", "pots", "tops"]]
```
Example 2:
```
Input: strs = ["x"]

Output: [["x"]]
```
Example 3:
```
Input: strs = [""]
 ```
